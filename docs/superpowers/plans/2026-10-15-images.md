# Images in notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Notes can show images that the browser (paste/drop) or the MCP (`add_image`) encrypts with the vault key and uploads as an opaque blob; the note body references them as `![alt](inked://<imageId>)`.

**Architecture:** One new SQLite table and two routes (`POST`/`GET /api/vaults/:vaultId/images/:imageId`) store `iv||ciphertext||tag` bytes. `core` owns the format (AAD, sniffing, token helpers). The web renderer turns `inked://` references into `<img data-inked-image>` placeholders that a view hook resolves through an in-memory `ImageStore` (fetch, decrypt, `blob:` URL). The MCP gets an `add_image` tool that fetches or reads bytes locally behind SSRF and path guards, then uploads through the same route. The CSP does not change.

**Tech Stack:** TypeScript, WebCrypto (AES-256-GCM), Fastify + `node:sqlite`, React + markdown-it + DOMPurify, MCP SDK + zod, vitest (+ jsdom for web).

**Spec:** `docs/superpowers/specs/2026-10-15-images-design.md`

## Global Constraints

Copied from the spec. Every task's requirements include these.

- Image blob format: `iv[12] || ciphertext||tag`, raw bytes (not base64), AES-256-GCM with the `vaultKey`, fresh random IV; AAD (UTF-8) is `inked/image/{vaultId}/{imageId}`.
- Allowed image types, detected by magic bytes after decrypt: png, jpeg, gif, webp. No SVG. The server stores no type.
- Max image: 10 MiB of plaintext. The server accepts at most 10 MiB + 28 bytes of blob (iv 12 + tag 16) and at least 29 bytes.
- Routes (cookie session + `X-Inked: 1` on writes, ownership checked like notes; foreign or missing vault/image is 404): `POST /api/vaults/:vaultId/images/:imageId` (`application/octet-stream`; 415 wrong type, 400 under 29 bytes, 413 over the cap, 409 if id exists, 413 `quota_exceeded` over quota, 201 `{ id, size, createdAt }`) and `GET /api/vaults/:vaultId/images/:imageId` (`application/octet-stream`, `Cache-Control: private, max-age=31536000, immutable`, `X-Content-Type-Options: nosniff`). No `DELETE` in v1.
- Quota: `INKED_IMAGE_QUOTA_MB`, default 1024, per user, `SUM(size)` over the user's vaults plus the new blob.
- Reference syntax: `![alt](inked://<imageId>)`; the vault is the note's vault. Cross-vault references are not supported.
- The CSP stays exactly `img-src 'self' data: blob:` / `connect-src 'self'` (+ `INKED_LLM_ORIGINS`). Public `<img>`/`<video>` never load; an external `![](https://…)` renders as a plain link.
- The server never learns type, dimensions, or which note uses an image.
- Decrypted images live in memory only (`blob:` URLs); revoke them on lock and sign-out. Nothing goes to localStorage, sessionStorage or IndexedDB.
- MCP `add_image`: new policy action `image.create` (not in any group, not granted by default); input `vault` plus exactly one of `url` (https) or `path`, optional `alt`. URL: https only, resolve DNS and refuse loopback/private/link-local/reserved IPv4 and IPv6, connect to the resolved address, re-validate every redirect hop, at most 3 hops, timeout, abort past the size cap. Path: refused unless it resolves (after symlinks) inside a folder in the config key `imageDirs` (default empty, so `path` is off).
- Out of scope: video, browser link import, orphan cleanup/`DELETE`, SVG, recompression, cross-vault references, a file-picker button, vault sharing.
- Commits: conventional commit subject, and end every commit message with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Branch: `feat/images` (already created; the spec is committed there).

## Deviation from the spec

The spec says the MCP audit log records the source URL or path. The audit log's rule is "ids only" (`mcp/src/tools.ts`, `ToolDef.touched`), and a source path or URL can reach logs the user shares. This plan records only the vault id and image id, and Task 12 corrects the spec line.

## Review Focus

The spec implies these inputs; each has a test in the named task.

1. **Mixed clipboard** (spreadsheet cells copy as text plus a PNG): pasting must insert the text as before, not an image token. Task 8.
2. **Missing, foreign or corrupt image** referenced in a note: that image shows "Image unavailable" and the rest of the note renders. Task 7.
3. **Lock or sign-out while a fetch is in flight**: no `blob:` URL survives in the cache and the late result is discarded. Task 5.
4. **Exactly-10-MiB image**: its blob is 10 MiB + 28 bytes, so the server cap must include the overhead; one byte more is refused. Task 4.
5. **Markdown-breaking alt text** (`](javascript:…)`, brackets, newlines) from the AI, and an SVG or HTML file renamed `.png`: the token stays one well-formed image reference, and sniffing rejects the file. Task 1 and Task 11.

```ts
import { aad } from './crypto/aad';
import { IV_BYTES } from './crypto/cipher';
import { concatBytes, randomBytes, utf8, type Bytes } from './crypto/encoding';
import { CryptoError } from './crypto/errors';

/** Largest plaintext image the browser, the MCP and the server accept. */
export const MAX_IMAGE_BYTES = 10 * 1024 * 1024;
/** iv[12] + GCM tag[16]: what an encrypted image adds to its plaintext. */
export const IMAGE_BLOB_OVERHEAD = 28;

export type ImageType = 'png' | 'jpeg' | 'gif' | 'webp';
export const IMAGE_MIME: Readonly<Record<ImageType, string>> = {
  png: 'image/png',
  jpeg: 'image/jpeg',
  gif: 'image/gif',
  webp: 'image/webp',
};

const at = (b: Uint8Array, sig: readonly number[], from = 0) =>
  b.length >= from + sig.length && sig.every((v, i) => b[from + i] === v);

/** The type from the first bytes, or null. SVG and HTML are never accepted. */
export function sniffImageType(b: Uint8Array): ImageType | null {
  if (at(b, [0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a])) return 'png';
  if (at(b, [0xff, 0xd8, 0xff])) return 'jpeg';
  if (at(b, [0x47, 0x49, 0x46, 0x38, 0x37, 0x61]) || at(b, [0x47, 0x49, 0x46, 0x38, 0x39, 0x61])) return 'gif';
  if (at(b, [0x52, 0x49, 0x46, 0x46]) && at(b, [0x57, 0x45, 0x42, 0x50], 8)) return 'webp';
  return null;
}

const subtle = () => globalThis.crypto.subtle;

/** `iv[12] || ciphertext||tag`, bound to the vault and image by AAD. */
export async function encryptImage(key: CryptoKey, vaultId: string, imageId: string, bytes: Uint8Array): Promise<Bytes> {
  const iv = randomBytes(IV_BYTES);
  const ct = await subtle().encrypt(
    { name: 'AES-GCM', iv, additionalData: utf8(aad.image(vaultId, imageId)) },
    key,
    bytes as Bytes,
  );
  return concatBytes(iv, new Uint8Array(ct));
}

export async function decryptImage(key: CryptoKey, vaultId: string, imageId: string, blob: Uint8Array): Promise<Bytes> {
  if (blob.length < IMAGE_BLOB_OVERHEAD + 1) throw new CryptoError('format', 'Image blob too short');
  const iv = blob.slice(0, IV_BYTES) as Bytes;
  const ct = blob.slice(IV_BYTES) as Bytes;
  try {
    const pt = await subtle().decrypt({ name: 'AES-GCM', iv, additionalData: utf8(aad.image(vaultId, imageId)) }, key, ct);
    return new Uint8Array(pt);
  } catch {
    throw new CryptoError('decrypt', 'Could not decrypt');
  }
}

const ID = '[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}';
const URI_RE = new RegExp(`^inked://(${ID})$`);
const REF_RE = new RegExp(`!\\[([^\\]\\n]*)\\]\\(inked://${ID}\\)`, 'g');

/** The image id in an `inked://<id>` uri, or null. */
export function parseImageUri(uri: string): string | null {
  return URI_RE.exec(uri)?.[1] ?? null;
}

/** `![alt](inked://id)`. Brackets, parentheses, backslashes and line breaks in `alt` become spaces. */
export function imageToken(id: string, alt = ''): string {
  const clean = alt.replace(/[[\]()\\\r\n]/g, ' ').replace(/\s+/g, ' ').trim();
  return `![${clean}](inked://${id})`;
}

/** Replaces each `![alt](inked://id)` with `alt`, so search and embeddings never see the uri. */
export function stripImageRefs(body: string): string {
  return body.replace(REF_RE, '$1');
}
```

```ts
export const DEFAULT_IMAGE_QUOTA_MB = 1024;
const MIB = 1024 * 1024;

/** INKED_IMAGE_QUOTA_MB: the most image bytes one user may store, in whole MiB. */
export function parseImageQuotaMb(value: string | undefined): number {
  const v = (value ?? '').trim();
  if (v === '') return DEFAULT_IMAGE_QUOTA_MB * MIB;
  if (!/^\d+$/.test(v) || Number(v) < 1) {
    throw new Error(`Invalid INKED_IMAGE_QUOTA_MB: ${value} (use a whole number of MiB, at least 1)`);
  }
  return Number(v) * MIB;
}
```

```ts
import type { FastifyInstance } from 'fastify';
import { type AppContext, currentUser, requireUser } from '../context.js';
import { nowIso } from '../db.js';
import { ApiError, notFound } from '../errors.js';
import { IMAGE_BLOB_MAX, IMAGE_BLOB_MIN, imageParams } from '../schemas.js';
import { ownedVault } from './access.js';

type ImageParams = { Params: { vaultId: string; imageId: string } };

export function imageRoutes(app: FastifyInstance, ctx: AppContext): void {
  const { db } = ctx;
  const auth = { onRequest: requireUser(ctx) };

  app.post<ImageParams & { Body: unknown }>(
    '/api/vaults/:vaultId/images/:imageId',
    { ...auth, bodyLimit: IMAGE_BLOB_MAX, schema: { params: imageParams } },
    async (request, reply) => {
      const userId = currentUser(request).id;
      const vault = ownedVault(db, userId, request.params.vaultId);
      const body = request.body;
      if (body !== undefined && !Buffer.isBuffer(body)) {
        throw new ApiError(415, 'unsupported_media_type', 'Send the image as application/octet-stream');
      }
      if (body === undefined || body.length < IMAGE_BLOB_MIN) throw new ApiError(400, 'invalid_request', 'Image data is too short');
      const { imageId } = request.params;
      if (db.prepare('SELECT 1 FROM images WHERE id = ?').get(imageId)) throw new ApiError(409, 'exists');
      const used = (
        db
          .prepare(
            'SELECT COALESCE(SUM(i.size), 0) AS n FROM images i JOIN vaults v ON v.id = i.vault_id WHERE v.user_id = ?',
          )
          .get(userId) as { n: number }
      ).n;
      if (used + body.length > ctx.imageQuotaBytes) {
        throw new ApiError(413, 'quota_exceeded', 'Image storage is full');
      }
      const now = nowIso();
      db.prepare('INSERT INTO images (id, vault_id, size, enc_blob, created_at) VALUES (?, ?, ?, ?, ?)').run(
        imageId,
        vault.id,
        body.length,
        body,
        now,
      );
      return reply.code(201).send({ id: imageId, size: body.length, createdAt: now });
    },
  );

  app.get<ImageParams>(
    '/api/vaults/:vaultId/images/:imageId',
    { ...auth, schema: { params: imageParams } },
    async (request, reply) => {
      const { vaultId, imageId } = request.params;
      const row = db
        .prepare(
          `SELECT i.enc_blob FROM images i JOIN vaults v ON v.id = i.vault_id
           WHERE i.id = ? AND i.vault_id = ? AND v.user_id = ?`,
        )
        .get(imageId, vaultId, currentUser(request).id) as { enc_blob: Uint8Array } | undefined;
      if (!row) throw notFound();
      return reply
        .header('content-type', 'application/octet-stream')
        .header('cache-control', 'private, max-age=31536000, immutable')
        .send(Buffer.from(row.enc_blob));
    },
  );
}
```

```ts
import { IMAGE_MIME, MAX_IMAGE_BYTES, sniffImageType } from 'inked-core';

/** A file that cannot be added; `message` is safe to show the user. */
export class ImageRejectedError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'ImageRejectedError';
  }
}

/** The bytes of a Blob; falls back to FileReader where Blob.arrayBuffer is missing (jsdom). */
export async function blobBytes(file: Blob): Promise<Uint8Array> {
  if (typeof file.arrayBuffer === 'function') return new Uint8Array(await file.arrayBuffer());
  return new Promise((resolve, reject) => {
    const r = new FileReader();
    r.onload = () => resolve(new Uint8Array(r.result as ArrayBuffer));
    r.onerror = () => reject(r.error);
    r.readAsArrayBuffer(file);
  });
}

export function validateImage(bytes: Uint8Array): void {
  if (bytes.length > MAX_IMAGE_BYTES) throw new ImageRejectedError('That image is larger than 10 MB.');
  if (!sniffImageType(bytes)) throw new ImageRejectedError('Only PNG, JPEG, GIF and WebP images can be added.');
}

export type ImageResult = { ok: true; url: string } | { ok: false };

export interface ImageBackend {
  /** The stored ciphertext blob. */
  download(vaultId: string, imageId: string): Promise<Uint8Array>;
  decrypt(vaultId: string, imageId: string, blob: Uint8Array): Promise<Uint8Array>;
}

interface UrlOps {
  makeUrl: (b: Blob) => string;
  revoke: (url: string) => void;
}

const key = (vaultId: string, imageId: string) => `${vaultId}/${imageId}`;

/** Decrypted images as blob: urls, in memory only. `clear` (lock, sign-out) revokes them all. */
export class ImageStore {
  private urls = new Map<string, string>();
  private inflight = new Map<string, Promise<ImageResult>>();
  private epoch = 0;

  constructor(
    private readonly backend: ImageBackend,
    private readonly ops: UrlOps = { makeUrl: (b) => URL.createObjectURL(b), revoke: (u) => URL.revokeObjectURL(u) },
  ) {}

  peek(vaultId: string, imageId: string): string | null {
    return this.urls.get(key(vaultId, imageId)) ?? null;
  }

  get(vaultId: string, imageId: string): Promise<ImageResult> {
    const k = key(vaultId, imageId);
    const hit = this.urls.get(k);
    if (hit) return Promise.resolve({ ok: true, url: hit });
    const running = this.inflight.get(k);
    if (running) return running;
    const epoch = this.epoch;
    const p = (async (): Promise<ImageResult> => {
      try {
        const blob = await this.backend.download(vaultId, imageId);
        const bytes = await this.backend.decrypt(vaultId, imageId, blob);
        const url = this.make(bytes);
        if (!url) return { ok: false };
        if (epoch !== this.epoch) {
          this.ops.revoke(url);
          return { ok: false };
        }
        this.urls.set(k, url);
        return { ok: true, url };
      } catch {
        return { ok: false };
      } finally {
        if (this.inflight.get(k) === p) this.inflight.delete(k);
      }
    })();
    this.inflight.set(k, p);
    return p;
  }

  /** Makes freshly encrypted bytes viewable at once, without a download. */
  put(vaultId: string, imageId: string, bytes: Uint8Array): void {
    const url = this.make(bytes);
    if (!url) return;
    const k = key(vaultId, imageId);
    const old = this.urls.get(k);
    if (old) this.ops.revoke(old);
    this.urls.set(k, url);
  }

  forget(vaultId: string, imageId: string): void {
    const k = key(vaultId, imageId);
    const old = this.urls.get(k);
    if (old) this.ops.revoke(old);
    this.urls.delete(k);
  }

  clear(): void {
    this.epoch++;
    for (const url of this.urls.values()) this.ops.revoke(url);
    this.urls.clear();
    this.inflight.clear();
  }

  private make(bytes: Uint8Array): string | null {
    const type = sniffImageType(bytes);
    return type ? this.ops.makeUrl(new Blob([bytes as BlobPart], { type: IMAGE_MIME[type] })) : null;
  }
}
```

```ts
function unavailable(alt: string): HTMLElement {
  const box = document.createElement('span');
  box.className = 'img-unavailable';
  box.setAttribute('role', 'img');
  box.setAttribute('aria-label', alt ? `Image unavailable: ${alt}` : 'Image unavailable');
  box.textContent = 'Image unavailable';
  return box;
}

/**
 * Fills the `img[data-inked-image]` placeholders in `ref` after each render: a cached image at once,
 * otherwise fetched and decrypted; a failure becomes an inline "Image unavailable" box.
 * `html` is a dependency because React rebuilds the placeholders whenever it changes.
 */
export function useInkedImages(ref: RefObject<HTMLElement | null>, vaultId: string, html: string): void {
  const store = useStore();
  useEffect(() => {
    const root = ref.current;
    if (!root) return;
    let live = true;
    for (const img of Array.from(root.querySelectorAll<HTMLImageElement>('img[data-inked-image]'))) {
      const id = img.dataset.inkedImage!;
      const cached = store.images.peek(vaultId, id);
      if (cached) {
        img.src = cached;
        continue;
      }
      void store.images.get(vaultId, id).then((r) => {
        if (!live || !img.isConnected) return;
        if (r.ok) img.src = r.url;
        else img.replaceWith(unavailable(img.alt));
      });
    }
    return () => {
      live = false;
    };
  }, [ref, store, vaultId, html]);
}
```

```ts
import { useCallback, useRef, useState, type ClipboardEvent, type DragEvent, type RefObject } from 'react';
import { imageToken } from 'inked-core';
import { describeError } from '../lib/util';
import { ImageRejectedError } from '../state/imageStore';
import type { AppStore } from '../state/store';

const isImage = (f: File) => f.type.startsWith('image/');

/** Image files on the clipboard. None when the clipboard also has text (a spreadsheet copy): that text pastes as usual. */
export function imageFilesToPaste(dt: DataTransfer | null): File[] {
  if (!dt || dt.getData('text/plain') !== '') return [];
  return Array.from(dt.files).filter(isImage);
}

export function imageFilesToDrop(dt: DataTransfer | null): File[] {
  return dt ? Array.from(dt.files).filter(isImage) : [];
}

/** `text` in place of [start, end), both clamped to the current body; `caret` is just after it. */
export function insertAt(body: string, start: number, end: number, text: string): { body: string; caret: number } {
  const s = Math.min(Math.max(start, 0), body.length);
  const e = Math.min(Math.max(end, s), body.length);
  return { body: body.slice(0, s) + text + body.slice(e), caret: s + text.length };
}

export interface ImageInsertOptions {
  store: AppStore;
  vaultId: string;
  textRef: RefObject<HTMLTextAreaElement | null>;
  /** The note body as last rendered. */
  body: string;
  setBody: (body: string) => void;
  /** True while the vault is locking: no new work starts. */
  disabled: boolean;
}

/** Paste and drop of image files into the note editor: token first, upload in the background. */
export function useImageInsert(o: ImageInsertOptions) {
  const [error, setError] = useState<string | null>(null);
  const bodyRef = useRef(o.body);
  bodyRef.current = o.body;
  const opts = useRef(o);
  opts.current = o;

  const insert = useCallback(async (files: File[], at: { start: number; end: number }) => {
    const { store, vaultId, textRef, setBody } = opts.current;
    setError(null);
    let { start, end } = at;
    for (const file of files) {
      try {
        const image = await store.prepareImage(vaultId, file);
        const token = imageToken(image.id);
        const next = insertAt(bodyRef.current, start, end, token);
        bodyRef.current = next.body;
        setBody(next.body);
        start = end = next.caret;
        window.requestAnimationFrame(() => textRef.current?.setSelectionRange(next.caret, next.caret));
        void store.uploadImage(vaultId, image).catch((e) => {
          const cleaned = bodyRef.current.replace(token, '');
          bodyRef.current = cleaned;
          setBody(cleaned);
          setError(`Could not upload the image. ${describeError(e)}`);
        });
      } catch (e) {
        setError(e instanceof ImageRejectedError ? e.message : describeError(e));
      }
    }
  }, []);

  const caret = () => {
    const ta = opts.current.textRef.current;
    return { start: ta?.selectionStart ?? bodyRef.current.length, end: ta?.selectionEnd ?? bodyRef.current.length };
  };

  const onPaste = (e: ClipboardEvent<HTMLTextAreaElement>) => {
    if (opts.current.disabled) return;
    const files = imageFilesToPaste(e.clipboardData);
    if (!files.length) return;
    e.preventDefault();
    void insert(files, caret());
  };
  const onDrop = (e: DragEvent<HTMLTextAreaElement>) => {
    if (opts.current.disabled) return;
    const files = imageFilesToDrop(e.dataTransfer);
    if (!files.length) return;
    e.preventDefault();
    void insert(files, caret());
  };
  const onDragOver = (e: DragEvent<HTMLTextAreaElement>) => {
    if (Array.from(e.dataTransfer.types ?? []).includes('Files')) e.preventDefault();
  };
  return { error, onPaste, onDrop, onDragOver };
}
```

```ts
import { promises as fs } from 'node:fs';
import { lookup as dnsLookup } from 'node:dns/promises';
import { request as httpsRequest } from 'node:https';
import { BlockList, isIP } from 'node:net';
import path from 'node:path';
import { MAX_IMAGE_BYTES } from 'inked-core';
import { ToolError } from './errors';

const MAX_HOPS = 3;
const TIMEOUT_MS = 15_000;
const TOO_BIG = 'The image is larger than 10 MB.';

const blocked = new BlockList();
for (const [net, prefix] of [
  ['0.0.0.0', 8], ['10.0.0.0', 8], ['100.64.0.0', 10], ['127.0.0.0', 8], ['169.254.0.0', 16], ['172.16.0.0', 12],
  ['192.0.0.0', 24], ['192.0.2.0', 24], ['192.168.0.0', 16], ['198.18.0.0', 15], ['198.51.100.0', 24],
  ['203.0.113.0', 24], ['224.0.0.0', 4], ['240.0.0.0', 4],
] as const) {
  blocked.addSubnet(net, prefix, 'ipv4');
}
for (const [net, prefix] of [
  ['::', 128], ['::1', 128], ['fc00::', 7], ['fe80::', 10], ['ff00::', 8], ['2001:db8::', 32], ['64:ff9b::', 96],
] as const) {
  blocked.addSubnet(net, prefix, 'ipv6');
}

/** Throws unless `address` is a public internet address (IPv4-mapped IPv6 is checked as IPv4). */
export function assertPublicAddress(address: string): void {
  const family = isIP(address);
  if (!family || blocked.check(address, family === 4 ? 'ipv4' : 'ipv6')) {
    throw new ToolError('invalid', 'That address is not a public internet address.');
  }
}

export interface HopResult {
  status: number;
  location: string | null;
  body: Uint8Array | null;
}

export interface FetchDeps {
  /** Every address a name resolves to. */
  lookup(host: string): Promise<string[]>;
  /** One request to `url`, connected to `address` (never re-resolved). No redirect is followed. */
  hop(url: URL, address: string, family: 4 | 6): Promise<HopResult>;
}

const bare = (hostname: string) => (hostname.startsWith('[') ? hostname.slice(1, -1) : hostname);

function httpsHop(url: URL, address: string, family: 4 | 6): Promise<HopResult> {
  return new Promise((resolve, reject) => {
    const host = bare(url.hostname);
    const req = httpsRequest(
      {
        host,
        port: url.port || 443,
        path: url.pathname + url.search,
        method: 'GET',
        servername: isIP(host) ? undefined : host,
        headers: { 'user-agent': 'inked-mcp', accept: 'image/png,image/jpeg,image/gif,image/webp' },
        // Pin the connection to the address that was validated.
        lookup: ((_h: string, o: { all?: boolean }, cb: (...a: unknown[]) => void) =>
          o?.all ? cb(null, [{ address, family }]) : cb(null, address, family)) as never,
        timeout: TIMEOUT_MS,
      },
      (res) => {
        const status = res.statusCode ?? 0;
        if (status >= 300 && status < 400) {
          res.resume();
          resolve({ status, location: res.headers.location ?? null, body: null });
          return;
        }
        const chunks: Buffer[] = [];
        let size = 0;
        res.on('data', (c: Buffer) => {
          size += c.length;
          if (size > MAX_IMAGE_BYTES) {
            req.destroy();
            reject(new ToolError('invalid', TOO_BIG));
            return;
          }
          chunks.push(c);
        });
        res.on('end', () => resolve({ status, location: null, body: new Uint8Array(Buffer.concat(chunks)) }));
        res.on('error', () => reject(new ToolError('invalid', 'The download failed.')));
      },
    );
    req.on('timeout', () => req.destroy(new Error('timeout')));
    req.on('error', () => reject(new ToolError('invalid', 'Could not download that image.')));
    req.end();
  });
}

const defaultDeps: FetchDeps = {
  lookup: async (host) => (await dnsLookup(host, { all: true })).map((r) => r.address),
  hop: httpsHop,
};

function parseHttps(raw: string): URL {
  let u: URL;
  try {
    u = new URL(raw);
  } catch {
    throw new ToolError('invalid', 'Not a valid URL.');
  }
  if (u.protocol !== 'https:') throw new ToolError('invalid', 'Only https:// image links are supported.');
  if (u.username || u.password) throw new ToolError('invalid', 'Links with a username or password are not supported.');
  return u;
}

/**
 * Downloads an image from a public https URL. Every address a name resolves to must be public, the
 * connection goes to the address that was checked, and each redirect hop is checked again (at most 3).
 */
export async function fetchImageUrl(raw: string, deps: FetchDeps = defaultDeps): Promise<Uint8Array> {
  let url = parseHttps(raw);
  for (let hops = 0; ; hops++) {
    const host = bare(url.hostname);
    let addresses: string[];
    if (isIP(host)) addresses = [host];
    else {
      try {
        addresses = await deps.lookup(host);
      } catch {
        throw new ToolError('invalid', 'Could not look up that host.');
      }
    }
    if (addresses.length === 0) throw new ToolError('invalid', 'Could not look up that host.');
    for (const a of addresses) assertPublicAddress(a);
    const res = await deps.hop(url, addresses[0], isIP(addresses[0]) as 4 | 6);
    if ([301, 302, 303, 307, 308].includes(res.status)) {
      if (hops >= MAX_HOPS) throw new ToolError('invalid', 'Too many redirects.');
      if (!res.location) throw new ToolError('invalid', 'The link redirects nowhere.');
      let next: string;
      try {
        next = new URL(res.location, url).toString();
      } catch {
        throw new ToolError('invalid', 'The link redirects to an invalid address.');
      }
      url = parseHttps(next);
      continue;
    }
    if (res.status !== 200 || !res.body) throw new ToolError('invalid', `The server answered ${res.status}.`);
    if (res.body.length > MAX_IMAGE_BYTES) throw new ToolError('invalid', TOO_BIG);
    return res.body;
  }
}

const inside = (dir: string, file: string) => {
  const rel = path.relative(dir, file);
  return rel !== '' && !rel.startsWith('..') && !path.isAbsolute(rel);
};

/** Reads a local image file, only from inside a folder in `dirs` (symlinks resolved first). */
export async function readImageFile(file: string, dirs: readonly string[]): Promise<Uint8Array> {
  if (dirs.length === 0) {
    throw new ToolError('denied', 'Local files are off. List folders as "imageDirs" in the Inked MCP config file to allow them.');
  }
  let real: string;
  try {
    real = await fs.realpath(file);
  } catch {
    throw new ToolError('not_found', 'File not found.');
  }
  let allowed = false;
  for (const dir of dirs) {
    const realDir = await fs.realpath(dir).catch(() => null);
    if (realDir && inside(realDir, real)) allowed = true;
  }
  if (!allowed) throw new ToolError('denied', 'That file is not inside a folder listed in "imageDirs".');
  const stat = await fs.stat(real);
  if (!stat.isFile()) throw new ToolError('invalid', 'That is not a file.');
  if (stat.size > MAX_IMAGE_BYTES) throw new ToolError('invalid', TOO_BIG);
  return new Uint8Array(await fs.readFile(real));
}
```
